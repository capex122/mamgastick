# Harbor Arabic & English Manga Sources

A community source repository for the Harbor manga reader.

## Add to Harbor

Copy and paste this repository URL into **Harbor → Manga → Set up a source → Extensions**:

```text
https://raw.githubusercontent.com/capex122/mamgastick/main/harbor-manga-sources/repo.json
```

[Open the Harbor repository manifest](https://raw.githubusercontent.com/capex122/mamgastick/main/harbor-manga-sources/repo.json)

## Available sources

- 3asq — Arabic
- Olympus Staff — Arabic
- Arcomix Verse — Arabic comics
- MangaDex — Arabic
- MangaDex — English

After adding the repository, install and enable the individual sources you want to use. Refresh or reinstall a source when a newer plugin version is published.
